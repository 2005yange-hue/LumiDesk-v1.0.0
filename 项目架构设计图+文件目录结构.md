> 基于多模态大语言模型与长期记忆机制的智能桌面虚拟伙伴系统

## 1.5 情绪状态流转

```
                    ┌─────────────────────────┐
                    │      Emotional State     │
                    │                          │
                    │  · happy    (开心度)     │
                    │  · trust    (信任度)     │
                    │  · affection(亲密度)     │
                    │  · energy   (精力值)     │
                    └───────────┬─────────────┘
                                │
          ┌─────────────────────┼─────────────────────┐
          │                     │                     │
          ▼                     ▼                     ▼
    用户正向反馈            时间推移              用户负向反馈
    (+开心/+信任)           (-精力值)            (-开心/+精力)
          │                     │                     │
          └─────────────────────┼─────────────────────┘
                                │
                                ▼
                    ┌─────────────────────┐
                    │   状态影响输出       │
                    │                     │
                    │ → 回复语气          │
                    │ → Live2D 表情       │
                    │ → Live2D 动作       │
                    │ → 主动行为频率      │
                    └─────────────────────┘
```

## 1.6 Agent 主动交互决策流程

```
                        定时轮询 (30s-60s)
                              │
              ┌───────────────┼───────────────┐
              │               │               │
              ▼               ▼               ▼
         屏幕状态快照     用户行为分析     时间上下文
         (VLM分析结果)   (操作持续时长)   (时段/日期)
              │               │               │
              └───────────────┼───────────────┘
                              │
                              ▼
                    ┌──────────────────┐
                    │   行为决策引擎    │
                    │                  │
                    │ 三重阈值判断：    │
                    │ ① 行为持续时长   │
                    │ ② 距上次发言间隔 │
                    │ ③ 重要性评分     │
                    └────────┬─────────┘
                             │
                    ┌────────┴────────┐
                    │                │
                    ▼                ▼
                 触发发言         保持沉默
                    │
                    ▼
             ┌─────────────┐
             │ 生成发言内容  │
             │ (带情绪参数)  │
             └──────┬──────┘
                    │
                    ▼
             ┌─────────────┐
             │ 系统通知推送  │
             │ Live2D表情切换│
             └─────────────┘
```

├──────────────┤      ├────────────────────────────────────────────┤
│  sad         │ ───► │  低落表情 + 低头 + 缓慢呼吸动作             │

├──────────────┤      ├────────────────────────────────────────────┤
│  thinking    │ ───► │  思考表情 + 歪头 + 手指点下巴               │
│  (思考中)     │      │                                            │
├──────────────┤      ├────────────────────────────────────────────┤
│  surprise    │ ───► │  惊讶表情 + 睁大眼睛 + 小幅度弹跳           │
│  (惊讶)      │      │                                            │
├──────────────┤      ├────────────────────────────────────────────┤
│  idle        │ ───► │  自然表情 + 随机微动作 + 呼吸起伏           │

├──────────────┤      ├────────────────────────────────────────────┤

## 2.2 核心目录职责速查

| 目录 | 职责 | 技术 |
|------|------|------|
| `electron/` | Electron 主进程：窗口、截图、通知、IPC | Electron API |

| `server/` | NestJS 后端：业务逻辑、LLM调用、数据库 | NestJS + TypeORM |

| `resources/` | 应用图标、SDK 等静态构建资源 | - |

## 2.3 模块间通信方式

```
┌─────────────────┐          HTTP/SSE          ┌─────────────────┐
│   Vue3 前端      │◄──────────────────────────►│  NestJS 后端     │
│   (渲染进程)      │   REST API + WebSocket     │  (业务逻辑)      │
└────────┬────────┘                             └────────┬────────┘
         │                                               │
         │  IPC (contextBridge)                          │ HTTP API
         │                                               │
┌────────▼────────┐                             ┌────────▼────────┐
│  Electron 主进程  │                             │  外部 LLM API    │
│  (截图/通知等)    │                             │  OpenAI 等       │
└─────────────────┘                             └─────────────────┘
```

- **Vue3 ↔ NestJS**：HTTP REST API（普通请求）+ SSE/WebSocket（流式响应）
- **Vue3 ↔ Electron 主进程**：IPC 通信（preload.ts 暴露安全接口）
- **NestJS ↔ 外部 LLM**：HTTP API 调用，带重试和超时机制
- **NestJS ↔ 数据库**：TypeORM 连接 MySQL，专用 SDK 连接 Chroma/Redis
